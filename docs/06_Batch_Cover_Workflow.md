# Batch Cover Workflow

CLI tool for finding and downloading book covers in bulk.

**Script**: `database/batch_covers.py`

## Quick Reference

```bash
cd database/

# Check current status
uv run python batch_covers.py status

# Export missing books to CSV
uv run python batch_covers.py export              # all missing
uv run python batch_covers.py export --limit 20   # first 20

# Fill in URLs in covers_batch.csv, then:
uv run python batch_covers.py import

# Review results
explorer.exe covers_review.html
```

## Workflow

### 1. Check the dashboard

```bash
uv run python batch_covers.py status
```

Shows a summary of how many books have/are missing covers and ISBNs.

### 2. Export missing books to CSV

```bash
uv run python batch_covers.py export
```

This creates `database/covers_batch.csv` with columns:

| book_id | title | author | isbn | url |
|---------|-------|--------|------|-----|
| abc123  | Book Title | Author Name | 978... | *(empty)* |

Use `--limit N` to export a smaller batch. Use `--output path` for a custom filename.

### 3. Find and paste cover URLs

Open `covers_batch.csv` in a spreadsheet or text editor. For each book:

1. Search for the book on [Goodreads](https://www.goodreads.com), Google Images, or Amazon
2. Right-click the cover image and copy the image URL
3. Paste the full URL (starting with `https://`) into the `url` column

Leave rows blank to skip them.

**Important**: When editing in a spreadsheet, make sure the empty `isbn` column is preserved — don't accidentally shift the URL into the wrong column.

### 4. Import and download covers

```bash
uv run python batch_covers.py import
```

For each row with a URL, the script:
- Downloads and validates the image (rejects tiny placeholders)
- Saves as `{book_id}.jpg` in `vue-app/public/covers/`
- Updates `manifest.json`
- Sets `hasCover=true` in the GeoJSON

### 5. Review results

The import generates `database/covers_review.html` — a visual grid of all processed covers with success/fail status.

```bash
explorer.exe covers_review.html
```

Failed downloads are shown with a red border and error message.

### 6. Repeat

Run `export` again to get a fresh CSV of remaining missing books. Work through them in batches of any size.

## Files

| File | Purpose |
|------|---------|
| `database/batch_covers.py` | The batch workflow script |
| `database/covers_batch.csv` | Generated by export, filled in by user |
| `database/covers_review.html` | Generated by import for visual review |
| `vue-app/public/covers/manifest.json` | Updated by import |
| `vue-app/public/litmap-data.geojson` | Updated by import (hasCover flag) |
