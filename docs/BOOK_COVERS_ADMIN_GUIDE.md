# Book Covers Admin Guide

How to download, manage, and manually add book cover images for LitMap.

## System Overview

LitMap stores book covers as local JPEG files in `vue-app/public/covers/`. Each file is named `{bookId}.jpg` and served statically by the Vue app. The frontend checks a `hasCover` flag in the GeoJSON data to decide whether to show the cover image or a colored placeholder.

**Current state**: 310 covers downloaded, 135 books still missing covers.

### Data Flow

```
Firestore (books + newbooks collections)
    ↓
export_geojson.py → litmap-data.geojson (sets hasCover flag by checking if file exists)
    ↓
download_covers.py → reads GeoJSON, downloads covers to vue-app/public/covers/
    ↓
Vue app → loads GeoJSON, displays covers from /covers/{bookId}.jpg
```

### Key Files

| File | Purpose |
|------|---------|
| `database/download_covers.py` | Main tool: downloads covers from Open Library & Google Books |
| `database/get_book_covers.py` | Legacy tool: updates Firestore `coverUrls` field (Open Library only) |
| `database/export_geojson.py` | Exports Firestore to GeoJSON, sets `hasCover` flag |
| `vue-app/public/covers/` | Directory containing all cover JPEGs |
| `vue-app/public/covers/manifest.json` | Tracks which bookIds have covers |
| `vue-app/public/covers/missing_covers.json` | Log of books where no cover was found |
| `vue-app/public/litmap-data.geojson` | Static data file consumed by the frontend |

## Tool 1: `download_covers.py` (Primary Tool)

This is the main cover download tool. It reads book metadata from the GeoJSON file, tries multiple API sources, validates the downloaded image, and saves it locally.

### Prerequisites

```bash
cd /home/ram/projects/LitMap/database
uv pip install requests Pillow
```

### How It Works

1. Loads all unique books from `litmap-data.geojson`
2. For each target book, tries cover sources in priority order:
   - **Open Library by ISBN** (fastest, most precise)
   - **Google Books by ISBN**
   - **Open Library by title+author search** (broader fallback)
   - **Google Books by title+author search**
3. Validates the image (rejects placeholders smaller than 10x10 pixels)
4. Saves as `vue-app/public/covers/{bookId}.jpg` (JPEG, 85% quality)
5. Updates `manifest.json` with new entries
6. Logs failures to `missing_covers.json`

### Commands

```bash
cd /home/ram/projects/LitMap/database

# Download covers for ALL books (overwrites existing)
python download_covers.py --all

# Download only for books that don't have a local cover file yet
python download_covers.py --missing

# Re-download covers flagged in Firestore (coverFlagged=True)
python download_covers.py --flagged

# Download cover for one specific book
python download_covers.py --book-id 09FpynNW0rFoRCHUjcO7
```

### Rate Limiting

The tool adds a 1-second delay between API requests. Open Library allows ~100 requests per 5 minutes. Google Books free tier allows 1000 requests per day. No API key is needed for either service in this tool.

## Tool 2: `get_book_covers.py` (Legacy)

An older tool that updates the `coverUrls` field directly in Firestore. It only uses Open Library and only works with ISBN-based lookups. Use `download_covers.py` instead for most tasks.

```bash
cd /home/ram/projects/LitMap/database
python get_book_covers.py
```

This updates Firestore documents with `coverUrls.S`, `coverUrls.M`, `coverUrls.L` URLs but does **not** download local files. The Vue app does not use these Firestore URLs; it uses local files.

## Manually Adding Covers

When the automated tools can't find a cover (no ISBN, obscure book, bad API results), you can add covers manually.

### Step 1: Identify the Book ID

Find the book's Firestore document ID. You can get this from:

- `missing_covers.json` (generated by `download_covers.py --missing`)
- The GeoJSON file (search for the title)
- The Streamlit admin tool (`streamlit run database/main.py`)

Example from `missing_covers.json`:
```json
{
  "id": "xYz123AbcDef",
  "title": "Where the Indus is Young",
  "isbn": "",
  "reason": "not_found"
}
```

### Step 2: Find the Cover Image

Sources for finding cover images manually:

1. **Google Images**: Search `"Book Title" book cover`
2. **Amazon**: Search the book, right-click the cover → "Copy Image Address"
3. **Goodreads**: Search the book, right-click the cover → "Copy Image Address"
4. **Open Library**: `https://openlibrary.org/search?q=TITLE`
5. **Google Books**: `https://books.google.com/books?q=TITLE`

Look for images that are:
- At least 100px wide (higher resolution is better)
- JPEG or PNG format
- The correct edition's cover

### Step 3: Save the Image

Save or download the image to the covers directory with the correct filename:

```bash
# Option A: Download directly from a URL
curl -o /home/ram/projects/LitMap/vue-app/public/covers/{bookId}.jpg "IMAGE_URL"

# Option B: Copy a local file (rename to bookId.jpg)
cp /path/to/downloaded_cover.jpg /home/ram/projects/LitMap/vue-app/public/covers/{bookId}.jpg
```

If the image is PNG or another format, convert it to JPEG:

```bash
# Convert PNG to JPEG using Python/Pillow
python3 -c "
from PIL import Image
img = Image.open('/path/to/cover.png').convert('RGB')
img.save('/home/ram/projects/LitMap/vue-app/public/covers/{bookId}.jpg', 'JPEG', quality=85)
"
```

### Step 4: Update the Manifest

Add the new entry to `vue-app/public/covers/manifest.json`:

```bash
# Use Python to add the entry
python3 -c "
import json
manifest_path = '/home/ram/projects/LitMap/vue-app/public/covers/manifest.json'
with open(manifest_path) as f:
    manifest = json.load(f)
manifest['BOOK_ID_HERE'] = 'BOOK_ID_HERE.jpg'
with open(manifest_path, 'w') as f:
    json.dump(manifest, f, indent=2)
print('Manifest updated')
"
```

Alternatively, run `download_covers.py --missing` after placing the file — it will skip books that already have a local file and update the manifest for files it finds.

### Step 5: Re-export GeoJSON (Required for `hasCover` flag)

The `hasCover` flag in the GeoJSON is set by checking whether the cover file exists on disk. After adding new covers, re-export:

```bash
cd /home/ram/projects/LitMap/database
python export_geojson.py
```

This regenerates `vue-app/public/litmap-data.geojson` with updated `hasCover: true` for books that now have cover files.

## Complete Workflow: Adding ~10 Covers

Here's a step-by-step walkthrough for manually adding roughly 10 book covers.

### 1. See What's Missing

```bash
cd /home/ram/projects/LitMap/database

# Try the automated tool first — it may pick up some
python download_covers.py --missing
```

Review `vue-app/public/covers/missing_covers.json` for books that still need covers.

### 2. Pick 10 Books to Fix

```bash
# View the first 10 entries in the missing covers log
python3 -c "
import json
with open('../vue-app/public/covers/missing_covers.json') as f:
    missing = json.load(f)
for i, book in enumerate(missing[:10]):
    print(f'{i+1}. {book[\"title\"]} (ID: {book[\"id\"]}, ISBN: {book[\"isbn\"]})')
"
```

### 3. Download Covers Manually

For each book, find and download the cover:

```bash
COVERS_DIR=/home/ram/projects/LitMap/vue-app/public/covers

# Example: download a cover from Google Books thumbnail URL
curl -L -o "$COVERS_DIR/xYz123AbcDef.jpg" "https://books.google.com/books/content?id=XXXXX&printsec=frontcover&img=1&zoom=1"

# Example: download from Open Library
curl -L -o "$COVERS_DIR/xYz123AbcDef.jpg" "https://covers.openlibrary.org/b/isbn/9780140192504-M.jpg"

# Example: download from Amazon
curl -L -o "$COVERS_DIR/xYz123AbcDef.jpg" "https://m.media-amazon.com/images/I/XXXXXX.jpg"
```

### 4. Validate the Images

```bash
# Quick check: verify all new images are valid
python3 -c "
from PIL import Image
from pathlib import Path
import sys

covers_dir = Path('/home/ram/projects/LitMap/vue-app/public/covers')
for f in sorted(covers_dir.glob('*.jpg'))[-10:]:  # check last 10 modified
    try:
        img = Image.open(f)
        w, h = img.size
        print(f'  OK  {f.name} ({w}x{h})')
    except Exception as e:
        print(f'  BAD {f.name}: {e}')
"
```

### 5. Update Manifest and GeoJSON

```bash
cd /home/ram/projects/LitMap/database

# Re-run with --missing: skips books that now have files, updates manifest
python download_covers.py --missing

# Re-export GeoJSON to update hasCover flags
python export_geojson.py
```

### 6. Verify Locally

```bash
cd /home/ram/projects/LitMap/vue-app
npm run dev
# Open http://localhost:5173 and search for the books you added covers for
```

## How the Frontend Uses Covers

The Vue app computes cover URLs from the book ID:

```javascript
// In BookCard.vue and BookDetails.vue
const coverSrc = computed(() => {
  return `${import.meta.env.BASE_URL}covers/${props.book.id}.jpg`
})
```

- If `hasCover` is true in the GeoJSON data, the component attempts to load the image
- If the image fails to load (404, corrupt), an `@error` handler hides it
- The fallback is a colored placeholder with a book icon, where the color is deterministically generated from the book title

Cover display sizes:
- **BookCard** (search results): 80x112px thumbnail
- **BookDetails** (detail view): 192x256px

## Troubleshooting

**"Book ID not found in GeoJSON"** when using `--book-id`:
- The book may not have been exported yet. Run `export_geojson.py` first, then retry.

**Cover downloads but shows as placeholder in the app**:
- Re-run `export_geojson.py` to update the `hasCover` flag.
- Clear browser cache or hard-refresh.

**Downloaded image is a placeholder (tiny or blank)**:
- The tool rejects images under 10x10px, but some valid-looking placeholders slip through.
- Check the image manually: `python3 -c "from PIL import Image; img=Image.open('covers/ID.jpg'); print(img.size)"`
- Replace with a manually sourced cover.

**No ISBN and title search fails**:
- Some books are too obscure for the APIs. Use manual download (see above).
- Try searching with just the title (without subtitle) or with alternate spellings.

**Rate limiting errors**:
- Wait 5 minutes and retry with `--missing` (skips already-downloaded covers).
- For Google Books, you may hit the daily 1000-request limit.
